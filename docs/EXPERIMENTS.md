# 当前实验设计与评测口径

当前配置采用medical-related-50-v2：原medical-related-30-v1的贫血、肾脏、甲状腺各10题保持原样及原顺序，追加原创MedQA风格20题（7/7/6）。原题已用于开发，新题为未经独立医学审题和难度标定的合成挑战题，不能宣称官方新增MedQA或独立未见测试集。新旧批次分别报告。

## 连续性

这是知识复用型连续任务流：前题产生的证据、查询经验及过程记录可被后题检索；各题本身可独立解答。候选关系仅供评估，不预置到Agent输入或初始记忆。通过实际记忆ID、来源任务、回读和引用追踪验证复用，不以题目主题相似或模型自称使用作为唯一证据。

## 四条件

| 条件 | 角色输入表示 | 跨题记忆 |
| --- | --- | --- |
| text_off | 自然语言任务与角色交接，不经过ACP | 关闭 |
| structured_off | ACP-1操作/引用派发，模型读取字段化内容视图 | 关闭 |
| text_on | 自然语言任务与角色交接，不经过ACP | 从空库开始在线积累 |
| structured_on | ACP-1操作/引用派发，模型读取字段化内容视图 | 从空库开始在线积累 |

当前每条件50题、共200次任务执行；历史30题批次每条件30题、共120次。条件与条件之间串行，条件内题目串行。条件顺序由种子42生成并保存，题序不打乱。模型、角色核心指令、语料、工具、证据处理和预算一致；Text有其输入和工具接口说明，structured启用role_views_v1时还包含上下文组织差异，因此不是只对数字编码做单因素归因。

旧格式实验的两种表示都共用三层封装，不能验证完整操作协议收益；旧结果保留。上述新设计版本为 `moreagent.handoff/1`，独立命名为 ACP-1，不标为论文 G²CP 的复现。详见 [实现说明](COMMUNICATION_IMPLEMENTATION.md)与[G²CP 对照核查](G2CP_COMPARISON_AUDIT.md)。

各条件数据库独立，不复用旧71题库或其他条件记忆。当前沿原30题→新增20题持续积累，题组切换时不清空；不能描述为每组独立冷启动。50题由slices.json分别统计原30、新20及新增各主题。need_first采用先规划、按需求召回、调查覆盖/仅查缺口、核验并可返回调查的流程。

## 分别测量

| 维度 | 指标与边界 |
| --- | --- |
| 答题 | 原始标准选项正确率、未答和运行失败；有答案不代表证据充分。 |
| 通信 | 角色请求/响应次数、字符、UTF-8字节、系统提示和控制字节；不是网络抓包包数。 |
| 模型成本 | API实际prompt/completion/total usage；缺失或未知用量明确记录。 |
| 状态 | 有负载的向量交换次数、float32负载字节、embedding耗时；非完整IPC总字节。 |
| 记忆 | 候选召回、展示、采纳、回读、策略执行、最终证据引用；来源有效不自动等于适用或正确。 |
| 重复工作 | 教材搜索、重排、来源回读、模型调用；减少检索次数不能直接称为减少模型推理。 |
| 效率 | 单题与整批耗时，额外编码/写入成本；续跑或共享资源影响另列。 |

当前四条件不单独隔离二进制状态编码的收益。若要作这项结论，需要对同一批向量单独比较JSON浮点数组与二进制的大小、编解码耗时、恢复误差和检索一致性。
