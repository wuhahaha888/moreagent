# JSON结构修复与实验恢复边界

当前解析先校验完整JSON。仅在decoupled模式、非截断响应中，允许修复一种可确定的结构错误：顶层对象提前以一个`}`结束，后面仍是逗号和完整的新字段；删除该唯一根闭合括号后，整段文本必须能完整解析，并保留所有原字段和值。

不截取第一个JSON对象、不丢弃后缀、不猜选项、不增写事实。重复字段、字段冲突、多对象、附带文字、截断、非有限数值及不完整后缀继续失败。修复后仍检查当前题号、角色契约、答案选项和来源；修复事件及字符位置进入审计，原始模型响应和原API用量保持不变。strict模式不启用结构修复。

## 本轮离线验证

原30题四条件实验`medical30-api-fourway-20261020-v2`已保存167次模型响应，其中166次JSON保持原样，1次为`structured_off / medqa::0512`的提前闭合错误。离线修复后经原始可见教材映射与结果校验，恢复选项B，与独立评分答案一致。该次没有调用模型、没有重新检索，也没有改写原在线报告或数据库。

这是一份单独的离线修复结果，不能把原在线24/26成绩直接覆盖成新在线成绩。复现命令（输出必须为新目录）：

```bash
python -B scripts/replay_medqa_json_repair.py \
  --source experiments/results/medical30-api-fourway-20261020-v2 \
  --output experiments/validation/medical30-json-replay-new
```

## 哪些任务需要再次执行

| 情况 | 处理 |
| --- | --- |
| 已保存合法响应与完整usage | 保留，可作受控离线重放，不重新调用API。 |
| JSON结构错误，但响应完整 | 先离线修复和校验；修复记录与旧成绩并存。 |
| API连接错误，没有保存响应 | 本地无法重放。继续该题需要新的API请求；原未知请求不自动记零成本。 |
| 尚未执行的任务 | 仍需运行，并保留原题序及对应记忆条件。 |

本轮已完成56次任务记录：text_on 30、structured_off 26。其中0512可离线恢复；1061的最后一次Reasoner请求缺失响应。尚未执行的任务为text_off 30、structured_on 30、structured_off 4，共64次。

修复解析器改变了源码指纹，原目录的普通`--resume`不能直接通过；也不能关闭校验、手改原账本或删除未知费用来强行续跑。后续执行应建立有来源记录的恢复批次，分别保留已有响应、离线修复、新请求与未知成本。若要采用新的恢复/重试策略，应在所有条件中一致使用并报告版本变化。恢复时延和原始不中断时延不直接混比。

本次实现和离线回放没有启动新付费请求；网络错误诊断与自动重试策略不在这次JSON补丁中修改。
