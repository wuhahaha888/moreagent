# 自然语言交接与 ACP-1 实现

版本：`moreagent.handoff/1`。当前业务答案协议仍使用 `moreagent.medqa/baseline-2` 的 JSON 结果结构；这不是通信版本。旧 30 题结果来自先前的格式对照，保持原样，不能合并为本版本结果。

## 两条实际路径

| 项目 | text | structured |
| --- | --- | --- |
| 模型接收的角色输入 | 自然语言任务、上游交接和原文资料 | 按业务字段组织的 JSON 内容视图 |
| 上游结果如何交接 | 从已有规划/查询结果生成自然语言段落；已有有效 handoff_text 时直接使用 | 注册任务、条件、需求、证据与记忆对象，通过引用解析 |
| 原仓库 G2CP 三层封装 | 不经过 | 不经过；改为自有 ACP-1，不称论文 G²CP 复现 |
| 协议解析及派发 | 不经过 ACP | HELLO、能力表、二进制位置参数、注册函数派发、结果/错误消息 |
| 模型输出 | 原角色 JSON 工具/结果接口，不原样透传给下一角色 | 相同角色 JSON 工具/结果接口，编译为协议操作 |
| 原工具逻辑 | 保留 | 保留，调用经过 ACP 能力与参数检查 |

自然语言不是字段字典换行缩进。`handoff.natural_message()` 输出可读段落，包含原题、所有选项、条件/需求关系、来源原文、查询历史、必要反馈和预算。程序不会解释或执行交接文字里的命令。默认不要求模型额外生成同义摘要，不增加模型调用；自然语言是已有结果的视图。额外提供的 handoff_text 被标记为模型撰写，模板生成则明确计数。两种模式都有本角色的 JSON 工具接口和业务校验，这是共享执行基础，不是 Text 模式进入 ACP。

## 已实现的 ACP-1

- `LangChain/medqa/acp.py` 定义 IntEnum、固定 18 字节头及 uint32 位置参数，检查版本、消息类型、参与方、长度和参数数量。
- 任务内 Session 真正编码 HELLO 与响应，读取能力描述后进入 ready；请求检查 ready、目标能力、调用方权限及类型化引用后，调用绑定函数。
- 三角色调用、教材搜索、来源回读、记忆召回/解析/写入均通过此派发路径。关闭记忆时不宣称记忆服务已就绪。
- 检索计划编译为带数字操作 ID、执行条件和前驱引用的批次。解码端从参数引用重建查询计划，实际执行顺序、条件、去重和资源限制沿用原搜索执行器。当前是串行执行，未新增线程并行；批次适配仅支持现有查询计划。
- 任务、证据视图、记忆视图、条件和知识需求保存在不可变对象表，接收方按类型引用回读。表只在当前任务 Session 内有效，不能跨任务照搬局部编号。
- 查询及记忆写入向量用 float32 bytes 登记为 state_id。记忆服务的已注册处理函数实际读取向量句柄并调用原 recall/put 方法；不重新生成同一向量。原独立记忆服务仍通过 Pipe 交换二进制向量。
- 错误记录 ERROR 帧并向调用者抛出异常，不增加自动付费重试。模型请求、工具结果和记忆提交仍由原 SQLite 检查点保护。

这是进程内二进制编解码和派发，未实现跨主机网络服务、共享内存生命周期、完整通用 DAG 并发执行或 G²CP 知识图谱。不要把帧数称为实际网络包数。

## 统计边界

每个角色事件保存准确的 `model_input`，可以检查下游模型是否实际收到自然语言。Text 的 ACP 指标应为零。结构化事件保存 `acp_handshake` 与 `acp_exchange.frames_hex`，可解析实际动作、参与方和参数引用。

`report.json.handoff_metrics` 单列 ACP 请求/结果字节、握手字节、登记内容序列化字节、证据/记忆引用回读、状态句柄消费、自然语言交接字符及模板生成数。对象登记量按内容 JSON 序列化或原始向量大小计，不等于 Python 内存占用或网络流量。`acp_dispatch_seconds` 包括调用回调耗时，`acp_overhead_seconds` 扣除回调后统计编解码/注册/派发开销；不能拿前者当纯解析耗时。

API 的真实 prompt/completion usage 照旧统计，不用 ACP 字节替代。接收角色仍会把必要正文提供给云模型，因此本次代码修改本身不保证 Token 节省。若自然语言与业务字段有不同取舍，其质量和成本都必须在真实对照中验证。

```bash
# 包含协议和实际模型输入检查，使用本地模型替身，无 API 费用。
bash scripts/run_medqa.sh test

# 新配置静态检查，不发生成请求。
bash scripts/run_medqa.sh audit \
  --config configs/medical-related-30-v1/compare-api-acp1.json --all

# 复现实验时使用独立新目录；既有批次与结果见reports索引。
bash scripts/run_medqa.sh compare \
  --config configs/medical-related-30-v1/compare-api-acp1.json --all
```
