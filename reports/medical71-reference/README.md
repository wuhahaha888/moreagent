## 成本从哪里来

纯文本记忆多85,469 token（22.95%）：Planner多63,406，Investigator多22,362，Reasoner少299。结构化记忆多92,843（25.91%）：分别多60,300、22,892和9,651。四条件每题都3次模型调用，记忆并未节省调用次数；教材检索分别少7次、少0次。

Planner为候选生成了449/456条判断，其中318/323条是拒绝。提示允许省略普通候选，但实际模型仍逐条输出大量记录。候选召回增加不但增加输入，也增加输出及后续规划负担。

记忆组确有原文核对的引用记录19/17、策略执行关联15/11；仅证明发生读取/声明使用，不证明答案改善或避免了计算。运行时embedding encode累计877/893秒（不含模型预加载及缓存I/O等），是耗时来源之一。

## 正确率变化与适用性

纯文本有2题从对变错、1题从错变对。结构化有3题从对变错，另1题从未答变正确；这个新增正确不能当成已证明的知识收益。单次轨迹不能确定每个变化由记忆导致：第一题Planner的on/off输入相同，纯文本输出也不同。

medqa::0114在两种无记忆条件下均选标准选项C，两种有记忆条件下均选B。日志显示Planner从历史记忆采用正常阴离子间隙/高氯性酸中毒线索；最终回答虽算出AG=139-(106+11)=22，仍转向该历史方向。这里展示了主题相似、来源可核对与适用当前条件之间的差距，不是独立医学审计。

本轮只比较新方案的记忆开关，没有全量legacy Top-3对照，故不能判断“新重排比旧方案改善多少”。无记忆路径已达69/71与70/71，准确率存在明显上限，减少重复调用和输入应成为记忆的主要验证目标。
